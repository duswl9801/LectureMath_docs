Annotation Tool Explaination

Annotation Rules

  • Fix speaker's location at the top-left corner.
  • Object naming.
    Type Description
    hw hand-written
    ts typeset
    speaker speaker
    logo logo
    Type Description
    tx text
    me mathematical expressions
    gr graph

    Example) hw_me_005 : The fifth hand-written mathematical expression object.

  • Generate an object after finishing the speaker's writing, i.e. when one can see the whole object.
  • If the content on the board remains invisible due to luminosity, even after the speaker has finished writing,
    the annotation should be annotated when it becomes visible.
  • Don't annotate if the object stays on the frame for less than 7 seconds.
  • The border of the object should fully surround the selected content.
  • Avoid overlapping between objects whenever possible.
  • If the object's shape changes, copy the object's previous position at the point where the change begins to prevent interpolation.
  • When you use the 'hide' and 'show' functions on the annotation tool, add objects at the start and end frames of transition.
    This will prevent interpolation.
  • When the portion of an object is being deleted and replaced, annotate the change as a new object.

  • Text should always be one line.
  • Create objects along the shape of the graph for the graph annotation.
  • Whenever possible to express the contents in LaTex, annotate them as mathematical expressions.
  • Annotate highlighted graphs, for example underlines or diagrams above the content, as separate entities from the highlighted content.
  • Annotate as separate entities the highlighted content and graphs; for example, underlines or diagrams above the content.

  • When the formula is a mix of text, mathematical expression, and graph (ex. side2->area), annotate the entire formula as mathematical expression.
  • Arrows can be mathematical expressions or graphs, depending on the situation. Irregularly shaped arrows are classified into graphs.
  • Units like cm can be either mathematical expressions or texts. Annotate as mathematical expression when the unit is with math formula.
  • Enumerations that are symantically expressed text, like numbers in chapters or choices in multiple-choice questions, are annotated as text.

  • Annotate / or \ (slash) to cross out numbers, as the part of the mathematical expression object.
  • If a slash extends across two mathematical expressions, it should be annotated as a separate object.

Before export segments and key-frames, please set VIDEO_BASED_ANNOTATIONS in the configuration file to 1 so that the program can extract high-quality key-frames.

Video Segments

- The video is divided into semantic temporal segments, sub topics, and unique content which is not continuous; typically, it is the point where a content deletion event occurs. (not erroneously)
- Try to get a segment point where the objects involved from the previous segment are all erased.
- Segment the video when the subtitles inform important content.

Key-Frames

- Key-frames represent each video segment. Key-frames show all the objects on the lecture board. Use two key-frames to involve all the objects on the board if no frames in the segment show the entirity of the objects.

[Example of a good key-frame]


- Avoid using extreme frames as key-frames like the beginning, the end, and the exact transition frames.
- For key-frames, try to take frames without the speaker or the speaker not facing the camera.
- For a moving typeset video segment, a single key-frame is sufficient.
- If a video segment contains no written content, saving a key-frame is not required.
